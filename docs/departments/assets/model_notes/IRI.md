# Iri — Current 3D Model Notes

Use the **current Cato 3D model** for shared mechanical/material language, not the old Iri PNG/WebP body.

## Identity target
- slender, precise, elegant technical chassis
- pearl/cream-white shell
- lilac/purple secondary accents
- cyan emissive visor/display language
- halo / ring / aligned antenna motif is a permanent visual identity cue
- refined paneling with clean, controlled geometry

## Proportion target
- one of the narrowest silhouettes in the cast
- approximately 1.78 m presentation cue
- long clean limb lines, narrow torso, restrained shoulder width
- should look precise rather than fragile

## Personality read
Measured, analytical, composed, exacting, quietly pleased when things line up correctly.

## Halo rule
The halo/ring is visual identity only. It must not imply scanning range, communications capability, sensors, or hidden knowledge.

## Do not bake in
- research pack
- data tablet/slate
- drone
- survey gear
- construction tools

Those are optional equipment layers.

## Approval check
At distance, Iri should be recognizable from the **slender pearl/lilac body + halo silhouette** before any accessory is attached.
